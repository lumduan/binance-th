# รูปร่างที่ยังไม่ยืนยัน (assumed shapes)

[หน้าแรก](../index.md) > แนวคิด > รูปร่างที่ยังไม่ยืนยัน

[English](../../concepts/assumed-shapes.md) · **ไทย**

binance-th ถูกสร้างทีละ endpoint เทียบกับ API จริง โมเดล response ส่วนใหญ่จึงตรงกับความจริงเป๊ะ มีเพียงไม่กี่ตัวที่ยัง
ยืนยันแบบสดไม่ได้ — พวกนั้นถูกทำเครื่องหมาย **⚠ ASSUMED** ไว้ และควรรู้ว่าตัวไหนบ้าง เพื่อจะได้ไม่เชื่อชุดฟิลด์ของมันมากเกินไป

## อะไรยืนยันแล้ว vs ยังสมมติ

| ส่วน | สถานะ |
|------|--------|
| REST สาธารณะ (ข้อมูลตลาด) | ✅ ยืนยันแบบสดแล้ว |
| Market WebSocket stream (depth/trade/kline/ticker) | ✅ ยืนยันแบบสดแล้ว |
| วงจรชีวิต listenKey + การเชื่อมต่อ user-data | ✅ ยืนยันแบบสดแล้ว |
| การอ่านแบบ signed (`account`, `wallet`) | ⚠ ASSUMED — สร้างโมเดลไว้ ยังไม่ยืนยันกับ response ที่มีคีย์ |
| ออเดอร์ (`create`/`cancel`/`query`) | ⚠ ASSUMED — ทดสอบด้วย mock เท่านั้น (มันขยับเงินจริง) |
| **event** ของ user-data (`executionReport`, `outboundAccountPosition`, `balanceUpdate`) | ⚠ ASSUMED — probe เห็น stream เชื่อมต่อ แต่ไม่มี event ยิงบนบัญชีที่นิ่ง |

สามแถวที่เป็น ✅ ถูกยืนยันแบบสดอีกครั้งเมื่อ **2026-08-25** บน **websockets 17.0.1** (ช่วง dependency ขยายเป็น
`<18.0`) และได้รูปร่างตรงกับที่ probe ชุดเดิมบันทึกไว้ทุกอย่าง การรันครั้งนั้น **ไม่ได้** เปลี่ยนแถวสุดท้าย — probe
เชื่อมต่อได้ แต่บัญชีนิ่ง จึงไม่มี `executionReport` ถูกส่งออกมาเลย มีเพียง order soak ที่ใช้คีย์เท่านั้นที่จะปิดข้อนี้ได้

## ทำไมถึงใช้ได้อยู่ดี

- โมเดล response ใช้ `extra="allow"` ดังนั้นฟิลด์ใดที่ตลาดส่งมาแต่ไม่ได้อยู่ในโมเดลจะถูก **เก็บไว้** ไม่ถูกทิ้งหรือ error —
  คุณอ่านมันได้เสมอผ่าน extras ของโมเดล
- ฟิลด์ที่คล้าย enum บน event ของ user-data ถูกกำหนดเป็น **`str` ดิบ** ไม่ใช่ enum ของไลบรารี ค่าที่ไม่คาดคิด
  (เช่นสถานะอย่าง `PENDING_CANCEL`) จึงทำให้การ decode พังไม่ได้

ข้อควรระวังเชิงปฏิบัติ: ให้ถือว่าชื่อ/ชนิดของฟิลด์เป๊ะ ๆ บนส่วนที่เป็น ⚠ เป็นของชั่วคราว อ่านเฉพาะที่ต้องใช้อย่างระวัง
และอย่าเหมาว่าฟิลด์หนึ่งมีอยู่แค่เพราะโมเดลระบุไว้

## ยืนยันด้วยตัวเอง

รีโพนี้แนบสคริปต์แบบ opt-in ที่มีการป้องกัน ซึ่งยืนยันรูปร่างของ event user-data ในที่สุด ด้วยการวางออเดอร์เล็ก ๆ
หนึ่งรายการที่ไกลจากราคาตลาด (มันจะค้างและถูกยกเลิกโดยไม่ fill) จับ `executionReport` จริง แล้วยกเลิก:

```bash
BINANCE_TH_SOAK=1 uv run python scripts/soak_userdata.py
```

มันจะปฏิเสธที่จะรันถ้าไม่มีทั้ง `BINANCE_TH_SOAK=1` และคีย์ และไม่มีวัน fill — แต่มันวางออเดอร์ **จริง**
ดังนั้นอ่านสคริปต์ก่อน ถ้าคุณรัน รูปร่างที่จับได้จะถูกนำกลับมาใส่ในโมเดลได้
